# Contributing

Thank you for helping improve this guide. Contributions that add clarity, fix errors, or document new scenarios are very welcome.

## What to Contribute

- **Bug fixes** — steps that are outdated or no longer accurate
- **New troubleshooting entries** — edge cases you encountered and solved
- **Device-specific boot key tables** — models not listed in the guide
- **Alternative tools** — other reputable offline recovery tools
- **Translations** — guides in other languages (add as `docs/lang/XX/`)

## What Not to Contribute

- Methods to bypass cloud-based Microsoft account restrictions (not in scope)
- Anything that enables unauthorized access to devices you don't own

## How to Contribute

1. Fork the repository.
2. Create a branch: `git checkout -b fix/your-description`
3. Make your changes. Follow the style of existing docs (Markdown, clear headings, tables where appropriate).
4. Open a pull request with a clear title and description of what changed and why.

## Style Guide

- Use **bold** for UI element names (e.g. **Start**, **Rufus**, **NTFS**).
- Use `code formatting` for key presses, file names, and commands.
- Use ✅ / ❌ / ℹ️ for quick visual scanning in tables and lists.
- Keep sentences short and direct — this is a technical guide, not an essay.
- Test your steps if possible before submitting.

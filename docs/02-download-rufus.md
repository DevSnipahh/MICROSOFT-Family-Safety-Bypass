# Step 2 — Download & Run Rufus

Rufus is a free, open-source tool for creating bootable USB drives. It's the most reliable option for flashing ISOs to USB on Windows.

## Download

1. Go to: **https://rufus.ie**
2. Under **Download**, grab the latest **portable** version (`.exe` file — no installation required).
3. Run it. Windows may show a UAC prompt — click **Yes** (Rufus needs admin rights to write to the USB drive).

## What You'll See

Rufus opens a single window with a few settings. You don't need to change most of them — the next step will walk through exactly what to set.
